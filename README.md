# Library-Kiosk
The Library Kiosk that helps people help to carry out books easily.

This project models a simple self-service kiosk for a library. Patrons use the
kiosk to browse available books, select a title, and check it out without
needing a librarian. The system generates a checkout confirmation for each
transaction and ensures no two patrons can check out the same physical book
copy at the same time.
